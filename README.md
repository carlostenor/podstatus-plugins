# Podstatus plugins

Podcast analytics for podcasters, podcast producers and agencies using [Podstatus](https://podstatus.com). Explore Apple Podcasts, Spotify and iVoox rankings, listener reviews and tracked keywords using your own account.

- [ChatGPT and Codex package](chatgpt/README.md): portable Agent Plugins format.
- [Claude package](claude/README.md): Claude plugin format, including a remote MCP connection and the podcast-review skill.

Both packages connect to https://podstatus.com/mcp using OAuth. Access is read-only by default. A Podstatus Professional or Network account with API access enabled is required. OP3 analytics require a separate OP3 connection and available data.

This repository contains only public plugin configuration, instructions, documentation and the Podstatus icon. It includes no application server, customer data or credentials. Directory review and publication are separate steps; this repository does not claim that OpenAI or Anthropic has approved a listing.
