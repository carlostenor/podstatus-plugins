## Full description

Podcast analytics for every podcaster, podcast producer and agency using Podstatus. Track Apple Podcasts, Spotify and iVoox chart rankings, compare ranking history, read listener reviews, explore tracked keyword positions and draft podcast performance reports as text. Downloads and audience analytics are available when the required OP3 connection and data exist.

Built for podcasters, podcast producers and agencies. Requires a Podstatus account with API access enabled. Connect your own account using OAuth; access is read-only by default and limited to your tracked podcasts and approved permissions. Account limits are shared with the REST API and other MCP clients.

This plugin does not provide YouTube metrics, a visual dashboard or guaranteed complete historical coverage. Missing data is reported as unavailable. The included connection reads existing data and drafts text summaries; it does not generate PDF reports.

## Access requirements

A Podstatus Professional or Network subscription with API access enabled is
required. OAuth DCR is the supported sign-in flow. No shared API key, client
secret or locally installed server is required. The default connection is read-only.

## Release notes

Version 1.2.2 packages the Podstatus MCP connection and podcast-review skill,
